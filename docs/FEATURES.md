# Признаки финальной скоркарты

Модель: логистическая регрессия на WoE, версия с внешними скорами (24 признака, Gini valid 0.502).
Версия без внешних скоров (Gini valid 0.417) использует те же признаки без трёх `EXT_SOURCE_*`
(22 признака: 21 из таблицы ниже и `age_years`, который в этой версии сохранил правильный знак).

Шкала: 600 баллов при шансах 50:1 (на 50 хороших 1 плохой), +20 баллов удваивают шансы.
Больше баллов = надёжнее. **Размах** = баллы лучшей корзины минус баллы худшей: насколько признак
может сдвинуть итоговый балл. Признаки отсортированы по размаху.

## Исключены из скоркарты

**По правилу знаков** (коэффициент оказался положительным, то есть «надёжнее → рискованнее»,
из-за мультиколлинеарности; признак удаляется, модель переобучается):
- `AMT_CREDIT` (обе версии): информацию о сумме уже несут `credit_to_goods` и `credit_term`.
- `age_years` (версия с EXT): возраст уже несут `EXT_SOURCE_1` (ρ = 0.60), стаж и `NAME_INCOME_TYPE`.
  В версии без EXT возраст остаётся. Аудит по возрасту на этапе 4 проводится независимо (решение 24).

**По IV < 0.02** (27 признаков): в том числе `annuity_to_income` (H2: значим, но практически
бесполезен среди одобренных), `pos_ever_demand` (сильный сигнал, но у 312 клиентов; кандидат в правило,
а не в скоркарту), флаги `has_*_history`.

**По корреляции WoE > 0.7** с признаком с бо́льшим IV: `bureau_days_since_last_credit`,
`inst_avg_days_late`, `inst_max_days_late`, `prev_refused_cnt`, `bureau_debt_to_income`,
`bureau_active_debt`, `ORGANIZATION_TYPE`, `days_employed_anomaly`, `prev_approved_cnt`.

**Не используется по решению 15:** `CODE_GENDER` (хранится только для аудита справедливости).
